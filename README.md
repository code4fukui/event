# event

> 日本語のREADMEはこちらです: [README.ja.md](README.ja.md)

A repository for managing event information for Code for Fukui.

## Website

- https://code4fukui.github.io/event/

## Features

- Manages event information using Markdown files.
- Automatically generates a static event website.

## Data

Event information is stored in individual Markdown files. See an example: [2021-06-25.md](2021-06-25.md).
