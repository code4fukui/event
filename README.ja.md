# event

Code for Fukuiのイベント情報を管理するためのリポジトリです。

## ウェブサイト

- https://code4fukui.github.io/event/

## 機能

- Markdownファイルを使用してイベント情報を管理します。
- 静的なイベントウェブサイトを自動生成します。

## データ

イベント情報は個別のMarkdownファイルに保存されています。例をご覧ください: [2021-06-25.md](2021-06-25.md)
